Cubix AI Studio — Complete Setup Guide (XAMPP / Windows)

This guide takes you from a fresh Windows machine to a fully working Cubix AI

Studio installation. Every step is written for beginners — no prior Laravel or

server experience needed.

STEP 1 — Install XAMPP

  1. Download XAMPP from apachefriends.org — choose the PHP 8.2 version.
  2. Run the installer, keep all defaults, install to C:\xampp.
  3. Open XAMPP Control Panel (search the Start menu).
  4. Click Start next to Apache and MySQL. Both status lights should

turn green.

If port 80 is blocked (IIS or Skype), click Apache → Config → httpd.conf and
change Listen 80 to Listen 8080, then restart Apache.

STEP 2 — Install Composer

  1. Download Composer-Setup.exe from getcomposer.org.
  2. Run it. When it asks for the PHP path, point it to:

C:\xampp\php\php.exe

  1. Finish the installer.

Verify in Command Prompt:


php -v
composer -V

Both should print version numbers.

STEP 3 — Install Node.js

  1. Download the LTS version from nodejs.org.
  2. Run the installer, keep all defaults.

Verify:


node -v
npm -v

STEP 4 — Create the database

  1. Open your browser and go to: http://localhost/phpmyadmin
  2. Click New in the left sidebar.
  3. Type the database name: cubix_ai
  4. Set collation to: utf8mb4_unicode_ci
  5. Click Create.

STEP 5 — Set up the backend

5.1 Copy the backend folder

From the product download, copy the backend folder to C:\. You should end

up with:


C:\cubix-api\
    app\
    bootstrap\
    composer.json
    artisan
    ...

5.2 Install PHP packages

Open Command Prompt and run:


cd C:\cubix-api
composer install

This downloads all required packages including Laravel, the PDF reader and the

Word file reader. It takes 2–5 minutes the first time.

5.3 Create your environment file


copy .env.example .env
php artisan key:generate

5.4 Configure the environment

Open C:\cubix-api\.env in Notepad. Set these values:


APP_URL=http://127.0.0.1:8000

DB_HOST=127.0.0.1
DB_DATABASE=cubix_ai
DB_USERNAME=root
DB_PASSWORD=

Leave everything else as-is for now.

5.5 Run the database migrations and demo data


php artisan migrate
php artisan demo:install

Type yes when asked. This creates all the database tables and fills the

site with professional demo content — tools, plans, pages, customers and

translated content.

Warning: demo:install deletes everything in the database and starts
fresh. Only run it on a new installation or when you want to reset to demo
content.

5.6 Create the storage symlink


php artisan storage:link

5.7 Start the backend server


php artisan serve

Leave this window open. The API is now running at http://127.0.0.1:8000

STEP 6 — Set up the frontend

Open a second Command Prompt window:


cd C:\cubix-ai-studio\frontend
npm install
npm run dev

Leave this window open. The frontend is now running at

http://localhost:5173

STEP 8 — Add an AI API key (required for text tools)

The image generator works immediately with no key. The text tools (content

writer, translator, chat, rewriter, summariser, document assistant) need one

API key.

Free options (no credit card required):

Google Gemini (recommended):

  1. Go to aistudio.google.com/apikey
  2. Click Create API key
  3. Copy the key

Groq (also free and fast):

  1. Go to console.groq.com
  2. Create an account and go to API Keys
  3. Click Create API key

Add the key to the platform:

  1. Sign in as admin at http://localhost:5173
  2. Go to Admin → Settings → AI Settings → API Keys
  3. Paste your key next to Google Gemini (or Groq)
  4. Click Test to confirm it works
  5. Click Save

STEP 9 — Test everything is working

Go through this checklist:

  • [ ] Home page loads with the demo content
  • [ ] Sign in as admin works
  • [ ] Go to Admin → AI Settings and test your API key
  • [ ] Open Tools → AI Image Generator, enter a prompt, click Generate
  • [ ] Open Tools → AI Content Writer, enter a prompt, click Generate
  • [ ] Open Pricing and confirm the demo plans show
  • [ ] Switch language to Spanish or Arabic — site should translate
  • [ ] Open Admin → Appearance → Loader and toggle the loading screen on

Setting up payments (optional for local testing)

Stripe

  1. Create an account at stripe.com
  2. Go to Developers → API Keys
  3. Copy the Publishable key and Secret key
  4. In admin go to Settings → Payments → Stripe
  5. Paste both keys and set mode to Test
  6. Click Save — plans are created in Stripe automatically

PayPal

  1. Go to developer.paypal.com and create an account
  2. Go to Apps & Credentials → Create App
  3. Copy the Client ID and Secret
  4. In admin go to Settings → Payments → PayPal
  5. Paste the credentials, set mode to Sandbox
  6. Click Save

Setting up Google sign-in (optional)

  1. Go to console.cloud.google.com
  2. Create a project, go to APIs & Services → Credentials
  3. Click Create Credentials → OAuth Client ID → Web application
  4. Under Authorized redirect URIs, add exactly:

http://127.0.0.1:8000/api/auth/google/callback

  1. Copy the Client ID and Client Secret
  2. In admin go to Settings → Sign-in options
  3. Paste both values and click Save
Google treats localhost and 127.0.0.1 as different addresses. Always use
127.0.0.1:8000 — not localhost:8000 — when testing locally.

Moving to a live server

When you are ready to go live on a real domain:

  1. Upload the backend folder to your hosting and run composer install
  2. Build the frontend: npm run build — upload the dist folder
  3. Point your web server document root to backend/public for the API
  4. Set APP_URL in .env to your real domain
  5. Update your Stripe and PayPal credentials to live mode
  6. Update the Google OAuth redirect URI to your real domain
